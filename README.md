# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/Probal2005/youtube-downloader.git
```

Go to project folder

```bash
cd youtube-downloader
```

Create virtual environment

### Linux / macOS

```bash
python3 -m venv .venv
```

Activate

```bash
source .venv/bin/activate
```

### Windows

```bash
python -m venv .venv
```

```bash
.venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

# ▶ Run

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
